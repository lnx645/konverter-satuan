# Konverter Satuan (CLI)

Program Python di terminal untuk mengonversi satuan:
- **Panjang:** km, m, cm, mm, mi
- **Berat:** kg, g, ton, lb
- **Suhu:** C, F, K

## Cara Menjalankan

```bash
cd konverter-satuan
python3 main.py
```

Lalu pilih kategori (1/2/3), masukkan nilai, satuan asal, dan satuan tujuan. Contoh sesi:

```
Pilih kategori (0-3): 1
Nilai yang mau dikonversi: 5
Satuan asal: km
Satuan tujuan: m
Hasil: 5 km = 5000 m
```

Pilih `0` untuk keluar. Tidak butuh library tambahan (murni Python 3 standar).
